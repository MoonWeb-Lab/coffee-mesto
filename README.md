# Кофе Место — Мобильное меню и сервис предзаказа

> Интерактивное мобильное веб-меню для городской кофейни и бистро завтраков **«Кофе Место»** (г. Минск, пр-т Независимости, 43).

Разработано **MoonWeb Lab** как современная, быстрая замена статической папке Google Диска в шапке Instagram профиля [@coffee_mesto](https://instagram.com/coffee_mesto).

---

## Возможности

- **Mobile-first UI (390px):** идеальная адаптация под мобильный трафик из Instagram и аккуратное центрирование на планшетах и ноутбуках.
- **Оптимизация изображений:** конвертация карточек из Google Диска в WebP со снижением размера файлов более чем на 96% (быстрая загрузка даже при слабом мобильном интернете).
- **Категории и поиск:** удобная навигация по разделам («Драники и горячее», «Сытные завтраки», «Сладкие завтраки», «Тосты и питы», «Спешелти кофе») и мгновенный поиск.
- **КБЖУ и состав:** подробный расчет калорийности, белков, жиров и углеводов на 100 г для каждого блюда.
- **Корзина и форматы заказов:**
  - «С собой ко времени» (быстрый предзаказ навынос без ожидания на месте);
  - «Бронь столика» (выбор удобного времени и количества гостей).
- **Интеграция с Telegram:** автоматическая генерация форматированного текста заказа для отправки в Telegram заведения.

---

## Стек технологий

- **React 18** + **TypeScript**
- **Vite 6** (быстрая сборка, base: './' для GitHub Pages)
- **Tailwind CSS 3** (минималистичная черно-белая палитра кофейни)
- **Framer Motion 12** (плавные анимации на LazyMotion)
- **Lucide Icons**
- **Canvas Confetti**

## Установка и запуск локально

```bash
# Клонирование репозитория
git clone https://github.com/MoonWeb-Lab/coffee-mesto.git

# Переход в папку проекта
cd coffee-mesto

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка продакшн-версии
npm run build
```
